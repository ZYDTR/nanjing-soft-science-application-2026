## 独立写作者仍缺的承重信息

1. **来源与决策权限的一页对照。** 用户确认的是“沿用学姐框架、允许确定边界、可能获得导师数据帮助”，见 `section-26.md`「最初的研究要求」和 `docs/current_brief.md`「用户已确认」。同类机构作配置单元、选择服务经费池、将“责任”改造为“公平/合格需求与基本可达性”、公平分母、可行域、两方案线性组合、方法删留、2021—2025 拟取年份，均由主 Agent 设计（大纲「一」「二」「来源入口」末段），不能写成用户、导师或学姐已拍板。原 HTML 的 36/12/120—180 样本数则是**前置 Agent 的计划建议**。建议写作者把三种来源并排放在入口，不靠上下文猜。
2. **学姐原文的可核证据及数学边界。** `workstreams/framework/report.md`「给主 Agent 的结论」「模型核验与迁移边界」「原文需慎抄的记号」提供页码与式号；仅靠大纲摘要仍不足以写正式 ZSG 式。原文式 4.12 的变量称谓与约束方向不一致，式 4.11、5.3 等另有疑点；Liu 等科技资源 ZSG 全文未得（大纲「写作中可以先固定的数学关系」、`docs/second_round_review.md`「制作和数据方面」）。公式稿可先写已定义清楚的预算守恒、上下限与情景组合；ZSG 须原页逐式核对模型方向、可调/不可调投入、重配规则、迭代及求解条件，核不清则只能写方法条件和待核符号，不能造出“已验证算法”。
3. **预算对象是否真实存在。** 长三角科技合作细则 P03 的“实施经费+后评价奖励”证明制度入口，不证明两笔预算可被合成同一自由池；创新券 P02 的省市兑付也不能当任意重分预算。大纲「一、1」「一、3」「二」写了限制，但尚无合格机构全集、固定合同承诺、可调额度、上/下限及分配权限；这些直接决定 `B,L_i,U_i,Δ_i` 能否填数。申报正文应写取得路径与失败后的分析层级，不能预报南京最优分配。
4. **真实网络与量表的证据区隔。** `section-11.md`「观察单位」「原始记录到网络的六步」要求事件 ID、双方、时点、状态及来源；大纲「社会空间网络与模型的实际连接」已纠正吴文问卷量表不可直接重建边。若交接不附网络最小字段和第二轮吴文证据卡的关键结论，写作者很可能把协议 85 组或自评合作程度用于网络密度、中心度计算；当前均未取得全量履约边。
5. **数据可得性的三个写法分支。** `section-9.md`「三层可行性路径」的 A=行政微观/关系/结果期，B=机构项目样本/履约/访谈，C=公开地区统计/政策/少量案例，比大纲中的“拟取得”更可操作。现有 446 条公开统计、21 篇转换 PDF、4 篇证据卡与未来匿名台账属于不同状态；`docs/first_round_review.md`「21篇文献已可访问」、`docs/second_round_review.md`「三份证据」有确切边界。正文方法承诺须随可得层级条件化，不能将 21 篇“已转换”写成“已精读”。
6. **正式交付格式与 MathType 验收。** `workstreams/template/format_spec.md`给出旧 A 表第四、第五部分的标题段+一格内容表、字体/行距/公式行和图的位置；旧文件实际是 Letter，但 `docs/first_round_review.md`「版式可实施」记录官方要求 A4。旧 A 表 77 个 `Equation.3` 对象只说明 OLE 格式，不证明 MathType 来源；本地新建、再编辑与回读仍未通过。大纲的 TeX 只是内容底稿，正式 DOCX 不能把公式图片或 OMML 直接标为满足 MathType。技术路线 SVG 可编辑，JPG 附件须小于 400KB，进 Word 后仍需实宽检查。写作者需要这个制作/验收限制，即使先只交正文与公式稿。
7. **引用可复核性。** 大纲引 P02/P03/P07、S01、M01 和三份第二轮证据卡；原 HTML `source-register.md` 同时含大量不同阅读状态的来源。交接包必须保留相对路径或随包稳定网址、证据页码和“已读/仅题录/未取得”标签；不宜只给本机绝对路径，也不应把 HTML 内旧“原文待核”与现行核验结果并列而不说明先后。
