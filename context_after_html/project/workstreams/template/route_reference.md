# 学长技术路线图结构参考

来源：`学长论文-江苏省建筑业低碳发展的治理机制.pdf`，PDF 物理第 34 页、论文正文印刷第 14 页，图 1-5“技术路线图”。已直接从原 PDF 渲染并查看 `senior_route_page34.png`；PDF 共 135 页。以下只分析图形组织，不迁移其建筑业内容到南京课题。

图的总架构是**左方法列 + 右研究内容主链**。顶端“研究方法或理论”横向指向“研究内容”；右侧主链由上向下以蓝色粗箭头连接 6 个虚线阶段框，末端进入“结论与展望”。每个阶段框顶部是浅灰底标题条，内部白底细框承载输入、分析对象、方法动作或产出。阶段之间留白明确，主方向始终向下；阶段内部用黑色细箭头表示并行、汇聚或串行关系。左方法列用细线接入相应阶段，右侧还有贯穿多阶段的细线与横向箭头，可读作跨阶段关联的视觉提示；图本身未给这些长连线单独命名，不能擅自解释为确定的因果反馈。

| 主链层 | 图内内容组织 | 对应左侧方法/理论 |
|---|---|---|
| 研究背景 | 国内外研究现状 ↔ 国内外实践探索，两块并列 | 文献分析法连入背景/概念区 |
| 概念及内涵 | 上方总概念框下分建筑业、低碳发展、建筑业低碳发展、治理机制四块，并有横向关联 | 文献分析法 |
| 江苏省建筑业碳排放度量及分析 | 建筑物化直接、建筑物化间接、建筑运营三路测算，汇入总量分解分析 | 碳排放系数法、投入产出法、混合 LMDI 方法 |
| 江苏省建筑业碳排放的系统仿真 | 影响因素选取 → 数据搜集 → 系统动力学模型建立与仿真结果 | 系统动力学 |
| 江苏省建筑业低碳发展的低碳治理路径 | 碳减排目标设定 → 路径识别 → 模型修正 → 情景模拟 | 情景分析法 |

用于南京项目图的**版式建议**：保留左侧方法/证据列与右侧主链，主链每层用灰标题条、虚线外框、内部并列/汇聚/串行小框；用一条清楚的竖向箭头连各层。研究内容的层数、节点名称、具体方法及数据输入由主 Agent 在研究框架定稿后确定，避免直接照搬建筑业六阶段。旧 A 表路线图版位宽约 6 英寸、高约 3.72 英寸，而学长图接近整页纵向；若按旧 A 表版位，需压缩为更少层或增大单图高度，确保打印后文字可读。2026 申报说明要求第一部分研究方案使用框图，若另传附件须 JPG 且不大于 400 KB；导出时应分别验收 Word 内图与附件 JPG 的文字清晰度。
