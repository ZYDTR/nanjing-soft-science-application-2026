# 文献证据提取 Skill 试用反馈

试用对象：冯兆奎硕士论文，项目内已有 64 页 CAJ 转 PDF。按 `rules/skills/workflow_literature_evidence_extraction.md` 定向阅读并完成 `evidence.md`、`reading_log.json`、关键页 PNG；未改 Skill。

清楚且有效的部分：Skill 明确区分定向选读与全文精读，要求承重断言定位到物理/印刷页、公式表格回看原页，以及将作者发现和迁移建议分开。这次正是靠回看式 (4.1)/(4.3) 与表 4-2/5-2，发现“投入导向”文字和产出扩张式冲突，以及 DEA 与 QCA 结果变量数值不能直接对接。对无原始数据时写“未复算”的要求也有用。

具体缺口与可改进处：

1. 两阶段论文建议增加一项“跨阶段变量桥接”核查：前阶段输出是哪张表、什么口径/年份/聚合，后阶段结果变量的描述统计是否能对上。此篇摘要称动态效率，正文只称 DEA 效率，表 5-2 均值 0.896 又不同于静态 TEC 0.828 和动态 TFP 1.033，现有通用项目虽能容纳，但没有显式提醒。
2. `reading_log.json` 示例的单个 `physical_page`/`asset` 适合单页断言；公式方向与数值冲突常跨多页和多个表，示例可允许 `physical_pages`、`assets`，并区分全部已看图与部分文字导航。
3. 可以明确“方法文本、数学式、软件设置可能互相冲突”，对 DEA/QCA 这类模型要求分别记录声称的方向、原式的方向、可得的求解文件。此篇投入/产出导向冲突和 α 判据异常，若只摘模型名称会遗漏。
4. 对样本量与可迁移性建议提醒区分作者自述限制、普遍方法要求及本项目数据现实。此篇作者称 30 案例低于最低要求，但不应据此误写为 QCA 一律至少某个固定样本数。

本次可完成性：清楚，未因 Skill 步骤发生阻塞。关键不确定性来自论文本身缺少年度映射、原始数据与模型工程文件，属于文献证据边界。
