# 文献证据提取 Skill 首次调用反馈

本次按 `rules/skills/workflow_literature_evidence_extraction.md` 定向精读 167 页 CAJ 转换 PDF。Skill 对“原文事实/迁移解释分离”“物理页+印刷页+表图定位”“公式和表格原页核对”“未复算不得称复现”的要求清楚且可执行；已有转换件优先使用也避免了重复转换。

建议主 Agent 后续评估两个可补缺口，本 leaf 未改 Skill：

1. 遇到标题含“网络”的问卷论文，可增加一个可选核查清单：是否有具名节点、可核验边、关系方向/权重、事件日期、边界与覆盖率；否则写明是关系*感知量表*或合作数量分档。本篇若只读标题和摘要，极易把三类问卷构念误写成已构建关系网。
2. `reading_log.json` 示例每条 claim 只设单一页与图片路径，但一条关键结论常跨量表、附录与结果多页。可明确允许一个主定位加 `supporting_pages/assets`，并要求“未见”结论说明检索与阅读范围；这样更方便审计否定判断，不会误将未见说成全文不存在。

另一个本篇特有风险是作者将修订后的 67 份预调研与 432 份正式问卷合并，且将所有必填答卷视为有效。Skill 的样本进入、排除和时间顺序字段足以促使记录该点，无需为此新增硬要求。
