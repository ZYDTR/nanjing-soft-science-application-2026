# 吴钊阳《资源配置视角下协同创新网络与企业成长的关系研究》定向证据卡

## 来源、范围与一句话判断

吴钊阳，电子科技大学管理科学与工程博士学位论文，2020 年 6 月授位（PDF 物理 2 页，题名页）。原件为 `资源配置视角下协同创新网络与企业成长的关系研究_吴钊阳(1).caj`；本次只读既有 167 页 CAJ 转换 PDF：`@repo/context_after_html/project/workstreams/literature/converted/资源配置视角下协同创新网络与企业成长的关系研究_吴钊阳(1).pdf`。根据项目 inventory，该转换件含原生可选文字；本次未重新转换、未取得原始问卷数据或计算代码、未复算。定向阅读物理页 2、5–6、22–24、56–57、95–99、101–107、113–125、126–140、142–148、163–166；重点表图和附录原页另存 `evidence/`。这是**定向精读**，不是全文精读。

**核心判断：**论文的实证“协同创新网络”是受访者对本企业与三类主体合作程度的问卷感知构念，辅以自报的当前合作主体数分档；不是由具名组织之间的合作事件构成的关系矩阵或时序网络。论文的“网络演化”主要是案例叙述、生命周期横截面比较及理论解释，未观察同一网络多期节点与边的变化。[E01–E04、E11–E13]

## 能证明到哪里：识别条件与未满足的条件

作者原意是用两个典型企业案例形成机制假设，再用横截面问卷的因子分析、SEM 和生命周期分组/交互回归检验。若将统计路径解释为因果链，必须额外相信：受访者对同一时点的合作、配置和绩效报告准确；不同问卷版本可合并；样本进入与未观测能力/产业/资源禀赋不会共同决定三者；网络合作先于配置、配置先于绩效；反向机制（优秀企业更易获得伙伴与资源）不足以解释结果。这些不是论文表 6-18、6-24、6-27 所识别或验证的条件。[E05、E07–E12] 论文能支持“在其便利样本和测量模型中，三类合作程度感知、配置能力自评、创新绩效自评显著相关，且关联随生命周期组别不同”。它不能证明真实网络结构、合作频次、资源流动、配置效率、政策净效应或动态双向循环。[E01–E13]

作者在方法表提到以单因子模型拟合差论证不存在共同方法偏差（物理 116 页／印刷 103 页，表 5-21）。本次没有看到多源外部结果或分时测量；单因子检验不能清除同一受访者自评三组核心变量造成的共同方法风险。样本是否每家企业只有一份答卷、问卷调查的具体日历日期、原始问卷与代码、间接效应抽样区间均未在本次定向阅读页中见到，保持未决。

## 南京研究的迁移判断（本次建议，不冒充作者结论）

1. **可借鉴的概念层级：**把需求方、供给服务方、组织主体的协同关系分类型，并把“接触/合作→资源匹配与配置→服务或创新结果”列成待验证的机制链；类型依据主要来自 [E02、E07、E10]。机构或项目层面的网络需要按真实事件重新定义“边”，不能直接沿用 A11–19 的 1–7 分称作事件网络。
2. **更合适的数据底座：**若南京可取得需求申报、服务受理/匹配、服务交付、项目共研、拨付与验收记录，以统一组织 ID、项目/需求 ID 和发生日期构建“需求—服务—主体”多层事件表，再按固定年度/项目阶段聚合边；区分一次接触、正式协作和服务完成，边权由次数、金额或完成结果分别表示。此为南京设计建议，正是 [E02–E03] 未做到的事项，不是吴文已有方法。
3. **把资源配置中介操作化：**南京若讨论同质可控资源池，记录预算、设备、专家工时等可分配资源的计划量、获配量、使用量与服务结果；“匹配是否适宜”的问卷可作为组织感知补充，不能代替流量和约束数据。[E07] 同时把责任、效率、综合视为基础机制内部的候选方案；网络协同和制度安排可作为解释与评估维度，避免把吴文单一中介构念直接扩张成多套配置算法。
4. **阶段差异只作待验异质性：**可预设机构/项目类型及成熟度分层，但不照搬其初创期偏企业、成长期偏政府、成熟期均衡的排序；原样本制造业 46.5%、成熟期 64.5%，且 H7a/H7c 未获支持。[E06、E12]
5. **主张强度随数据走：**只有单期事件/问卷时可做协同图谱和相关诊断；有前后期记录且主体 ID 可追踪，才可检验关系重组、需求响应速度和服务结果；若要称制度机制的因果效果，还需政策前后及可比对象/明确的选择规则，处理合作与绩效的双向选择。[E11–E13] 吴文最适合支撑“组织协同通过资源匹配影响结果”这一待检验机制，不适合作为南京已建真实事件网络、可优化分配公式或已证明政策因果效果的证据。
