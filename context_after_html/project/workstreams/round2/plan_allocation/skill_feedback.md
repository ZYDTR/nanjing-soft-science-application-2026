# 文献证据提取 Skill 首次实用反馈

本次调用的文件：`rules/skills/workflow_literature_evidence_extraction.md`。目标清楚，尤其是“定向精读不冒充全文精读”、公式/表格必须回看页图、原文与迁移建议分开、负面发现也要记录，直接帮助避免把 0/1 模型误写成已实证求解，并避免把已立项项目当成全部申请者。

具体可改进处，供主 Agent 后续判断；本次未改 Skill：

1. **影像转换件的“原页”层级可再定义**。本次可视核对的是转换 PDF 渲染页，原 HN 容器不能像普通 PDF 一样直接读取。建议将“原件容器页”“转换 PDF 页”“OCR 文本”分成三个核验层级；若仅对转换页目视，卡片需明确保真限制。
2. **转换警告计数口径应统一**。王文日志有 26 个警告页，每页 Image Count 和 Truncating 各一条，共 52 条。Skill 可示例同时记录“受影响页数”和“警告行数”，避免把 52 条误解成 52 页。
3. **长篇影像论文的定向终止条件可更具体**。本文 217 页且无文字层，本轮按目录局部 OCR 107 页，真正承重图证 36 页。建议规定在已覆盖“概念定义—模型式及变量—数据进入与案例结果—限制/结论”后即可停止，记录未读区；不需为“全文”的形式目标耗费全部 OCR。
4. **“提出模型”和“用数据求解模型”的判别可增一条硬检查**。论文第 4.3 节有完整 0/1 模型，案例第 7 章却只有历史获资助组合、地区选择和系统仿真。建议证据卡必答：是否给全部候选集、参数、约束值、求解结果、对照方案及代码。缺一项就限制相应复现/应用表述。
5. **项目层级与区域层级变量混用应要求显式标注**。王文同时用 122 个已立项项目、24 产业、13 地区、30/31 省年统计和系统动力学情景。Skill 的研究设计清单有观察单位和样本期，建议增加“同一论文多模块时逐模块标单位、时期、数据来源与相互连接方式”；这样能直接识别“省级相关系数不等于项目资助效应”。

本次没有碰原件、转换件、共享日志、Skill 或其他工作流目录；产物仅在 `workstreams/round2/plan_allocation/`。
