06_调研工具/01_抽样与访谈实施方案.md
调研实施方案：当前为研究设计，未开展访问
1. 样本不只来自“愿意介绍的成功案例”
建议以园校合作、都市圈合作项目、创新券服务和概念验证为四类抽样框。优先争取完整名录后进行分层选择。官方85组园校关系[P07]只是名录存在的线索，不是已经取得的抽样框；报道列出的机构[P09]也不是全体服务机构样本。
首轮工作量建议36次半结构访谈，可按8次管理/计划执行、8次高校/科研或平台、12次企业需求方、8次中介/园区运营安排；同一案例访问双方可能占多个访谈次数，不等于36个独立案例。根据饱和程度、拒访和类别缺口再调整，不承诺这些数量已经实现。
从完整关系名录中建立约12组对比案例，以“申请前条件相近、实际推进状态不同”为选择原则。必须覆盖未形成合作、签约未完成、完成未持续、持续协作等状态。状态需初访或台账确认，不能根据宣传频次分类。产业、规模、成立年限、距资源距离、既存合作与政策支持组合均需记录。
问卷建议120—180份有效组织答卷，主要用于整理需求、障碍和服务体验。这个数量不是经过功效计算的因果识别承诺。框架无法覆盖总体时，报告招募路径和响应情况，不标成全市代表调查。
2. 邀访话术（可直接修改使用，尚未发送）
“我们正在研究科研服务与跨组织合作实际怎样发生，希望了解一次具体合作或一次未完成需求的经历。访谈不是对贵单位考核，也不要求介绍商业秘密。您可以跳过问题或停止参与。我们将区分个人观点、机构记录与公开资料，未经单独同意不会以可识别方式引用。”
录音、记名引用、再次联系分别确认，不用一次笼统同意覆盖全部用途。提供记录回看只核对事实，不让任何单一主体代替研究结论。
3. 时间线追踪是访问主轴
以需求登记→寻找伙伴→报价/技术对接→审批/签约→实际实施→验收/收款→后续合作为框架。每个节点问日期、责任方、费用、所需材料、失败或反复的情况、支持性文件。没有某节点的记录时，标明回忆估计，不帮受访者补齐一个顺畅故事。
先请受访者自由叙述，再按清单补问；先问实际做法，再问政策理解和建议。避免预设“行政壁垒”“资源浪费”“某制度有效”。不同参与方对同一事件不一致时，记录双方版本和凭据，不通过多数意见决定事实。
4. 反事实问题只作为机制材料
“没有支持会怎样”记录为受访者判断，不当成观测到的反事实。追问是否有当时预算、替代供应方、已作决定等证据。企业说“肯定不会做”与申请前已签订单同时存在时，保留矛盾并解释时序。
5. 访问后24项最小归档
匿名案例ID、抽样框、选择理由、未进入样本原因、机构类别、技术领域、地点、访问日期、职能、同意范围、关系起点、政策版本、真实需求、替代方案、报价、签约、实施、付款、成果时间、失败节点、证据ID、异议、需要回访的问题、研究者不能确认的事项。
本轮没有形成任何“已访谈纪要”。后续模板中的空格和未知值不得作为完成记录报出。
