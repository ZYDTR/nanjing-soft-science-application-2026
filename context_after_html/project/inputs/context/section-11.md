真实社会空间网络构建协议（可实施规格）
1. 明确网络的观察单位
建议主网络保留“需求方—服务事件—供给方”的事件结构，另建组织—协同项目和组织—专利—技术关系。后两类分别表达参与和知识关系，不等同付费服务。[M16提供共同专利及多类网络的研究线索；本包事件协议为研究设计]
网络时间以事件发生为准。签约网络、实际履约网络、付款网络分开；政策前形成的合作与政策后新增合作分开。多个新闻稿报道同一项目不是多条新边。
2. 原始记录到网络的六步
第一步：冻结原件。
登记持有者、取得日期、覆盖范围和权限；保留原始字段及文件哈希。本轮官方统计PDF未落地，不编造其本地哈希。
第二步：机构匹配。
先统一机构法定标识，再处理别名和改名。总部与分公司、大学与独立平台不因名称相似就合并。自动匹配保存相似候选，歧义进入人工复核；保留匹配置信类别而非伪精确概率。
第三步：历史地点。
按事件发生时的注册、实际服务和统计归属分别链接。行政区与园区不是同一层级。无法归区的记录进入“未明确归属”，并报告其权重占比。
第四步：事件去重。
按服务子项/合同/验收/付款流水确定粒度；同一合同多次付款不是重复。冲突金额、双方名称或日期不直接取最大值，先回源。代码只演示同一事件同状态同单位的完全重复，真实分期应补payment_id。
第五步：分层聚合。
服务金额、服务小时、合同次数、专利数量分别形成边层。不以未经验证汇率或权重把它们合为单一“资源流”。合作项目多方先保留双模或超边；投影必须披露规则。
第六步：质量报告。
输出覆盖机构比例、无法匹配ID比例、未知地址比例、缺失履约期比例、只有签约无完成的比例和关联关系待核比例。每个比率同时给出分子、分母、期间和来源总体。
3. 合作专利的分数计数规则
对于一件含k个组织申请人的专利，机构贡献可分别用完整计数1或分数计数1/k作敏感性比较，两种结果不能混用。投影到无向组织对时，可对每对赋1/组合数(k,2)，使单件专利贡献的边权和为1；也可选其他理论权重，但必须注明理由。k=1的专利不产生组织合作边，仍留在组织成果表。金额不能用这种对称规则冒充合同真实资金流向。
专利申请年、授权年和公开年不同；技术分类、多申请人、同族和法律状态观察日要保留。跨境同族去重与国内不同专利号不能凭字符串相似度替代。
4. 可达性指标与分母
需求完成率
＝观察期内完成的有效需求数／同一批次、足够跟踪时间的有效需求数。不能用报道中的67个签约项目除以718条需求，因为口径、去重和批次尚未核实。[P09]
首次匹配时长
＝首次合格报价或正式对接日期－需求登记日。尚未匹配的需求右删失，不能赋0天或删除不计。
跨区外部服务比例
＝已确认跨区的外部服务量／地点可核实的外部服务量；同时报告地点未知部分。组织注册地跨区和服务实际跨区分别算。
持续合作比例
＝足够观察期内有后续实际合作的首次合作对／同批首次合作对。对失访给上下界或单列未知，不把未知当终止。
容量利用率
＝同口径实际占用开放时长／可用开放时长。先扣除按规则定义的不可用时段，不能用自然年8760小时统一当每台设备分母。
网络密度
需要固定节点边界和类型。企业—平台双模网络的潜在边是符合技术和资格规则的可行配对，不一定是所有节点任意相连。新增小机构进入可能改变密度，即使真实边增加也不能直接比较为“关系变差”。
5. 不用中心度直接分奖励
中心度可能反映历史规模、机构类型、被记录概率或“自己参与很多”，不等于增加了多少有价值的合作。奖励研究应先核对新增履约、服务覆盖、对照/基线与归因规则，再讨论中心度是否提供补充信息。需要披露单一大机构退出、遗漏未获支持企业、不同窗口和不同分数计数规则下，网络结论是否稳定。[M04/M07、M05、M15]
6. 与配置模型的连接
政策前真实网络可以给出技术可行配对、服务供给上限和既有关系；政策后网络用于观察新增联系。不能用同一个后验网络先设计权重、再用它证明设计有效。只有引力估计时，称为潜在联系或基于假设的匹配，不称真实流动。
