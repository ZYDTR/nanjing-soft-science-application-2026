三、碳配置与创新资源的概念差异
以下是一般对象性质的比较，不声称是学姐论文的假设或结论。
可分性不同
：预算可以连续近似，完整项目、核心团队和特定设备采购不一定能拆分。整项目选择需要整数变量；不能把一台设备按35%分给一个区、65%分给另一区，除非定义的是使用权或使用时段。
零和边界不同
：同年度同类预算池可以固定总额；知识扩散、联合研发产出和开放服务供给可能因协作改变。ZSG适用性应落实到某一种受约束资源，而不是泛称“创新资源总和不变”。[M01,M02,M08]
权属与决定权不同
：配置对象是否可调整取决于资金用途、合同、资产使用权和成果协议，不能以所在地代替统筹权限。[P08,P10]
跨区流动的含义不同
：购买服务可能不要求资产搬迁。应区分拥有、控制、使用和受益；跨区服务流的存在也不意味着某区资源减少。
绩效时滞不同
：技术服务履约与基础研究产出有不同时间尺度。同年度专利/资金比值不可自动解释为当年投资效率。[M09]
奖励存在反馈
：若先按网络中心性给资源，再用分配后网络中心性证明规则优越，就会形成设计内循环。奖励指标应基于配置前冻结记录；结果验证使用后续独立观察。
四、两个可并行保留的技术分支
分支A：严格复现学姐后做最小迁移。
取得原文后复现原数据或作者示例，再逐项改变量和约束。优点是继承关系清楚；限制是可能发现原模型并不适用于服务或多种资源，此时需要明示改造而不是伪装一致。
分支B：先建立可用的配置外壳与数据治理。
已提供的连续预算约束代码只处理预算守恒、上下限、资格和敏感性。未来可以接入经验证的ZSG输出或其他竞争份额，但当前没有把它命名为ZSG-DEA。
两条分支的共同核心是三类配置框架；算法实现必须等待原文与实际数据条件共同确认。这样的边界不会阻止现在开展真实数据整理、制度研究和调查准备。
