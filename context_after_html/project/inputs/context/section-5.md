02_文献研究/02_文献综合与可检验贡献.md
文献综合：不是把方法串在一起，而是明确每一段解决什么问题
1. 四条文献线，各自承担不同任务
资源配置与效率线[M01、M02、M03、M08、M09]回答“相对投入产出表现怎样、既定约束下如何分配”。网络与邻近线[M04/M07、M05、M16]回答“哪些主体通过什么关系接触资源、关系怎样形成和演化”。资助评估线[M10、M11、M12、M13、M15]回答“观察到的变化是否由支持引起、是否持续、谁还受到间接影响”。配置组态方法讨论[M06]提醒我们，制度条件组合必须建立在可比较案例与可解释反事实上。
四条线可以相接，但不能用一条线的结果代替另一条线的证明：效率边界不是因果效应，网络中心度不是贡献净值，获资助项目的增长不是资助带来的增长，案例故事也不是净效应估计。
2. 本项目可检验的贡献表述
贡献A：把“资源所在地”与“资源实际可达”分开。
地区资源存量不能识别企业是否接触、购买或共同使用服务。新增之处应表现为一套可追溯的需求—服务—主体关系数据和可达性指标，而不是在题目加上“社会空间”。是否真正形成该贡献，取决于能否获得需求与履约事件。
贡献B：把“资源评价总体”与“可调整资金池”分开。
评价驻宁创新体系可以较宽，但模拟只能对有权限、有年度、有用途的同类对象实施。基准不是宣称所有资源均应被重新分配，而是比较明确约束下不同目标的结果。是否形成贡献，取决于预算授权和固定承诺账本能否核实。
贡献C：把配置、连接、结果写成有时间顺序的机制。
政策在t期改变哪项资格、价格或匹配机会；t至t+1发生何种实际服务；之后出现哪些结果。网络既可作为政策前条件，也可作为政策后的中介，二者不可不加区分地放进同一个回归。
贡献D：把公平与效率的选择透明化。
公平的分母、服务门槛、最低保障、能力上限与权重应显式公开。研究比较取舍及敏感性，不把一套客观权重包装成唯一应当选择的政策。
以上是本轮提出的潜在贡献，尚不宣称国内外“首次”或已有创新成果。新颖性最终需要对学姐原文、导师指定21篇CAJ和更完整数据库检索确认。
3. 几个应该被允许失败的假设
H1：技术适配和既有协作比直线距离更能解释特定服务是否发生。可证伪路径：控制需求后地理因素仍主导，或没有稳定差异。需要未成功需求与成功服务共同组成分母。[理论动机M04/M07、M05]
H2：中介对接更可能缩短首次合作的搜寻时间，而非普遍提高所有后续成果。可证伪路径：相似未使用中介的需求也同样快速完成；或者改善只来自企业自选择。[评估设计动机M10、M12]
H3：只按规模配置与按需求/服务缺口配置，会产生不同的覆盖和承接负担。这个假设可由模拟检验配置差异，但不能直接由模拟证明真实福利改变。
H4：新增连接不一定形成持续合作。可证伪路径：多数新增合作在多个观察期继续由企业自费维持。短期与长期应分开观察。[动机M12]
H5：地区/机构网络位置影响政策外溢，直接未获支持者可能间接受益。可证伪路径：在已定义的暴露范围内没有可辨识变化，或外部影响与政策无关。[动机M15]
4. 文献提取的统一模板
每篇完整阅读至少交付：研究对象和时期、观察单位、样本进入机制、资源/结果定义、变量时点、识别或优化假设、边界/预算约束、原始数据入口、算法和复现材料、稳健性、作者承认的限制、可迁移与不可迁移的部分、支持上述内容的页码。现在没有读到正文的文献，其页码必须留空。
检索记录还应保存不支持原假设的结果、效果减弱或没有效果的研究、实施失败和不同受益主体，而不只收集“政策有效”的文章。
