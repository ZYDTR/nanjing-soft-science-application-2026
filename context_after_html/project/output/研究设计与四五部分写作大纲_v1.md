# 研究设计与第四、第五部分写作大纲

2026-09-23｜研究设计稿，供后续申报书写作使用；不是已经完成的南京实证结论。

本项目研究“资源在哪里、主体能否用到、怎样在权限范围内改善配置”。整体沿用学姐的**基础配置—竞争配置—奖励配置**机制框架；公平、效率、综合是基础配置内部的三个初始方案。地区分布用于识别差异，真实合作与服务关系用于解释障碍，同类资金池用于比较可实施的调整方案。

## 一、本轮确定的研究边界

### 1. 评价对象较宽，配置对象明确

全市诊断覆盖人才、研发经费、创新平台与科研设施、科技金融及知识成果，分别记录规模、结构、空间归属和使用条件。人才数量、设备时长与资金金额各自计量，不合成为一笔可随意调拨的总额。

配置模拟以**同一管理权限、同一年度、同一用途的市级科技服务支持经费**为对象，优先研究创新资源供需对接服务。剔除已经形成合同承诺、用途锁定和无调整权限的部分，研究新一轮可调整额度的方案。基础研究基金、创新券兑付、机构实施经费、事后奖励分账分析，不互相挪作同一个池。

这不是将课题缩成一项补贴政策：全市资源统筹仍是研究总体；明确资金池是让定量配置模型具有现实含义。人事、设施共享、成果权益和跨部门协同主要进入制度分析、网络约束与案例比较。

这一分层有文献依据：王雪原论文同时讨论广义人财物信息资源和政府科技经费的项目选择，后者明确受到预算与支持份额约束。但其项目组合模型未展示可复用的逐申请数据与优化解，南京的参数和结果须自行建立。[定向证据卡E01—E04、E08、E13](../workstreams/round2/plan_allocation/evidence.md)

### 2. 地区负责汇总，机构和服务事件负责机制识别

| 层次 | 观察单位与用途 | 边界 |
|---|---|---|
| 地区诊断 | 行政区—年度；比较存量、投入、使用和受益分布 | 江北新区与行政区、园区保留独立管理字段，经映射后汇总，避免重叠相加 |
| 网络分析 | 需求方—服务事件—供给方；中介另作角色记录 | 签约、实际履约和付款分层；市外合作方作为外部节点保留 |
| 配置测算 | 同一服务类型、同一资助阶段的合格服务机构 | 单独建模，不把高校整体、园区、企业和单个项目混为一组 DEA 单元 |
| 机制比较 | 同类资源对接服务项目或合作事件 | 城市政策比较与项目组态比较分开，城市、机构、项目不混为 QCA 案例 |

从学姐的地区配额转为同类机构经费分配，是本项目明确作出的迁移：先形成机构方案，再按服务受益地汇总地区公平与覆盖，避免把机构注册地等同全部受益地。机构同质性以服务功能、投入产出过程和资助阶段判断，不以单位名称相似判断。

### 3. 实证主场景和资料来源

主场景为**创新资源供需对接与跨组织科技服务**。长三角（南京都市圈）科技合作计划提供“机构选择—合同任务—实施经费—绩效评价”的现实制度入口；园区高校合作提供跨组织联系和项目抽样入口；创新券提供设施服务交易及需求方进入条件的比较材料。三类材料互相补充，分别建账。

现行科技合作细则包含实施经费与后评价奖励；创新券细则规定省市联动兑付且有效期至2026年10月31日。因此，后续研究按政策版本记录规则，不能预先假定研究期内创新券规则不变，也不能把现行兑付资金写成可重新自由分配的预算。[P03][P02]

拟取得2021—2025年可比年度资料；2026年记录截至提取日的过程信息，未满观察期的项目不与完整年度成果直接比较。已有材料只证明公开统计、政策和文献可以提供起点；行政微观台账、完整机构名录及访谈资料仍是拟取得数据。

## 二、框架怎样形成闭合研究设计

| 机制 | 本项目研究内容 | 与三方案的关系 | 主要证据 |
|---|---|---|---|
| 基础配置 | 明确资格、任务、可调整总额、最低保障和承接上限，形成初始方案 | 在同一对象、总额和约束下比较公平、效率、综合三个初配方案 | 财政与合同台账、合格需求、机构能力、历史投入产出 |
| 竞争配置 | 研究公开遴选、跨区供需匹配、服务选择和依规调整如何改善初配后的实际使用 | 分别观察三种初始方案在相同竞争规则下的表现；必要时再单独改变一项规则作比较 | 申请、评审、报价、匹配、履约和退出记录 |
| 奖励配置 | 根据核验后的服务质量、新增覆盖与持续协作研究后评价和下一轮激励 | 评价三方案的实施表现，反馈到下一轮资格、约束和支持规则 | 合同任务、验收、受益方核验、后续合作记录 |

三个机制是分析层次，并不声称每项现实政策都严格按三步先后执行；竞争性遴选也可能发生在首次拨款之前。“竞争”不意味着可买卖财政拨款资格；“奖励”不等于给网络中心度高的主体加钱。

### 三个初始方案

**公平方案**以合格服务需求和基本可达性为依据。优先补足缺乏服务渠道的有效需求，在任务成本与承接能力允许范围内比较机会覆盖。人口、面积和历史创新存量用于地区背景与敏感性分析，不自动成为机构资金份额的法定依据。机构需求量须按去重后的任务归属计算；尚未匹配的需求单列，不能从分母删除。

**效率方案**保留学姐固定总量下的 ZSG-DEA 配置思路，限定在同质机构、明确可调投入及可比较产出上。历史测度优先采用少量可核验指标，例如同口径服务投入、服务人员投入，以及实际完成的服务任务和外部服务覆盖。新资金总量约束不意味着创新成果总量也必须固定。不同服务领域分别建模，不承诺增加指标或拼接年份一定能解决样本不足。

**综合方案**比较公平与效率之间的透明权衡。以两种可行初配方案的组合形成候选，检验最低保障、承接上限、调整幅度和地区受益。权重作为政策偏好参数展示敏感性；不直接移用学姐碳配置权重，也不用熵权法把数据离散程度解释成公共价值的重要程度。

### 写作中可以先固定的数学关系

令 \(b_i\) 为同一资金池分给机构 \(i\) 的可调整支持额，\(B\) 为该池总额度；\(L_i,U_i\) 为最低任务保障和可承接上限，\(b_i^0\) 为基准额度，\(\Delta_i\) 为允许调整幅度。统一可行域写为：

\[
\mathcal F=\{\boldsymbol b:\ \sum_i b_i=B,\ L_i\leq b_i\leq U_i,\ |b_i-b_i^0|\leq\Delta_i\}.
\]

正式使用前检验该集合非空。若合格需求不足以承接原预算上限，先单列未分配余额，并为三方案共同确定可行的实际比较总额 \(B\)；不把未分配额塞给虚构任务。若最低保障等约束互相冲突，报告不可行及冲突来源，不靠自动放松政策硬约束制造方案。资格、用途或技术配对不相容的事项另设硬约束。

若公平与效率方案 \(\boldsymbol b^F,\boldsymbol b^E\) 都属于同一凸可行域，则：

\[
\boldsymbol b^C(\alpha)=\alpha\boldsymbol b^F+(1-\alpha)\boldsymbol b^E,\qquad 0\leq\alpha\leq1.
\]

该式只表达初配方案的权衡。它不把基础、竞争、奖励拆成三笔预算，也不证明综合方案在所有指标上同时最好。整项目拨款等离散约束存在时，组合后须重新求取可执行方案，不能直接小数分配。

ZSG-DEA 的具体投入方向、非可调投入约束和迭代形式在正式公式稿中逐式核验。学姐原文部分记号有疑点，外部科技资源 ZSG 论文目前仅取得摘要及首页预览；本稿不把尚未核实的式子当成已验证算法。[S01][M01]

### 社会空间网络与模型的实际连接

网络至少记录三个不同量：资源所在地、技术与组织关系上的可接近程度、已经发生的服务使用。政策前关系和机构技术能力用于识别可行伙伴、服务半径与容量；履约后的新增联系和续约用于结果观察。未经履约证据支持的引力联系，只能作为潜在联系，不能代替真实服务网络。

吴钊阳论文可借鉴的是“协同关系—资源配置能力—绩效”的待检验机制，其问卷合作程度与合作主体数量分档不能直接成为南京事件网络。[定向证据卡E02—E03、E07](../workstreams/round2/collaboration_network/evidence.md) 冯兆奎论文提供效率测度与组态衔接的流程参照，但后阶段结果变量的时期、汇总与前阶段表值缺少可核对桥梁；本项目须让每个阶段的变量可追溯，不直接搬用其路径结论。[定向证据卡E07、E14—E15](../workstreams/round2/efficiency_configuration/evidence.md)

分配规则的效果通过覆盖率、需求完成、等待时间、跨区服务、资源使用效率和调整成本比较。若没有足够跟踪期与识别条件，报告模型内情景差异和机制证据，不声称测得财政支持的净因果效应。

| 方法 | 本稿定位 | 使用条件和取舍理由 |
|---|---|---|
| 资源清单、政策与合同分析 | 核心 | 明确权属、管理权限、重复统计和制度环节 |
| 真实关系的社会网络与空间分析 | 核心 | 以机构ID和服务事件建图；分层记录地点、距离和服务类型 |

| 公平、效率与可行性联合评价 | 核心 | 公平必须说明分母；效率依共同评价口径；调整成本与接受意愿由合同和调研支撑 |
| 蒙特卡洛模拟 | 参数稳健性工具 | 只扰动有资料或明示区间支持的需求、成本、能力与偏好参数，保留相关结构；每次检验约束，不把随机结果校准成“证明有效” |
| 跨城市政策比较、项目过程追踪 | 核心 | 有同类制度对象、实际事件和反例；比较实施条件及迁移成本 |
| QCA | 满足案例条件时的补充 | 同类项目、统一结果期、可证据化校准及足够组态多样性；不能把几个城市介绍凑成因果路径 |
| 共同前沿 / SBM | 不堆叠承诺 | 学姐共同前沿按方案分组且采用传统DEA；本研究优先固定历史参考口径评价方案，另建前沿须解释目的，不能由模拟数据制造“全面有效” |
| 修正引力、空间计量、RDD/DiD | 不列为必做主线 | 有具体问题、真实样本和识别条件再启用；不因旧模板出现这些方法就全部保留 |

## 四、第四部分的大纲与段落职责

标题：**四、本项目研究的主要思想、观点和理论方法**。

### 4.1 主要思想和观点

**4.1.1 从资源集聚转向资源可达与实际使用。** 解释资源存量、空间距离、组织连接和实际使用的区别；以同一需求从提出到履约的过程界定社会空间网络视角。提出待检验观点：资源集聚能否转化为使用机会，取决于技术适配、跨组织联系和制度安排。

**4.1.2 基础、竞争、奖励相衔接的统筹配置。** 说明三种机制各解决什么问题，公平、效率、综合三初配方案置于何处；讨论固定总量、权属与承接能力约束。提出待检验观点：同一投入下，初配规则和后续使用规则共同影响受益分布与执行绩效。

**4.1.3 以制度组合和实施条件形成分阶段路径。** 解释资格互认、供需匹配、利益约定、过程协调、绩效核验之间的联系；将效率集中和机会覆盖的取舍公开呈现。观点均写为研究判断或待检验命题，不写为已证实南京结论。

### 4.2 研究思路

按“概念与权限边界—现状及网络诊断—配置模型与机制设计—方案评价与稳健性—同类案例比较—实施路径”展开。每一环写清输入资料、具体工作和交给下一环的结果。

本节集中说明双层证据：地区统计回答总体差异；机构—服务数据解释可达性和配置过程。资源评价与资金模拟连接于同一组制度问题，不混合统计层级。

### 4.3 理论方法

建议依次为：4.3.1 资源界定与分层指标；4.3.2 社会空间网络构建；4.3.3 固定总量下三方案配置；4.3.4 公平—效率—可行性评价及参数模拟；4.3.5 跨案例机制比较与路径归纳。

每个方法只保留承担实际研究问题的公式、变量及边界。正文重点公式约6—8组，具体数量服从解释需要；公式编号采用本节连续编号。所有公式在最终DOCX内以MathType嵌入，当前数学表达只是内容底稿。

## 五、第五部分的大纲与实施安排

标题：**五、研究方案（包括技术路线图）**。沿用旧表“方案概述—方法和实施内容—路线图”的阅读顺序。

### 5.1 总体方案与资料组织

首段交代南京研究总体、资源供需对接主场景、三个初始方案及多维评价。明确统计数据、政策合同、业务记录、访谈问卷和跨城市案例分别服务什么问题。

### 5.2 调查对象、样本依据与证据取得

拟覆盖科技管理与计划执行部门、第三方科技服务机构、高校院所与平台、企业需求方及园区运营方。先争取合格申请总体和完整项目名录，再按服务领域、机构性质、地区覆盖和推进状态分层；纳入未入选、未匹配和中止项目。

首轮数据盘点须取得四类匿名样表：计划执行方的申请、评审、合同与拨付记录；服务机构的需求、撮合、履约和结算记录；需求方的实际使用、未采用原因与后续合作记录；统计与成果数据库的地区指标、机构地址和成果关联记录。以稳定机构ID、项目/需求ID和实际发生日期连接，先验证字段能否贯通，再扩大采集。只有汇总统计时不声称已取得全市服务网络。

沿用前置工作提出的36次半结构访谈工作量，约12组推进结果不同的配对案例；问卷暂以120—180份有效组织答卷组织需求与障碍调查。以上是计划量，访谈次数不等于独立案例数，问卷量不构成因果识别功效保证。数量根据名录覆盖、拒访和信息饱和调整。[H15]

城市层面选择有同类制度可对照的创新城市，以政策文本、实施资料和必要访谈比较；项目层面使用同一类型的事件作过程追踪。是否开展QCA在案例资料盘点后按明确条件确定，不以增加问卷替代案例证据。

### 5.4 技术路线图

采用学长图“左侧方法/证据、右侧研究主链”的结构。主链分六层：边界与理论 → 现状及真实网络 → 三机制与三初配方案 → 多维评价和参数稳健性 → 同类案例与机制比较 → 分阶段实现路径。反馈箭头从评价和案例环节回到机制设计，含义是研究修正，不代表已实施政策反馈。
