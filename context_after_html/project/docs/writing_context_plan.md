# 后续写作按缺口加载上下文

下一阶段以[研究设计与四五部分写作大纲](../output/研究设计与四五部分写作大纲_v1.md)为内容主入口。文献和历史合订本保留为可定位的证据库，不再全量塞入写作上下文。

| 何时加载 | 材料 | 要解决的问题 |
|---|---|---|
| 开始写作时 | `current_brief.md`、本轮设计稿、`research/official_notice_check.md` | 范围、匿名与格式要求、研究对象和已作取舍 |
| 写机制框架时 | `workstreams/framework/report.md`，矩阵中对应页及原页图 | 三机制与三初配方案的关系；哪些是原作、哪些是南京改造 |
| 写具体模型时 | 对应证据卡、原公式页、符号与数据规格 | 方向、单位、总量约束、适用样本；摘要不足时单独补全文 |
| 写数据及调研方案时 | `inputs/context/section-9.md`、`section-11.md`、`section-15.md` | 数据取得、事件连接、样本与反例；不把拟采集写成已完成 |
| 写案例和实施路径时 | 对应政策原文、定向文献中的过程证据 | 制度环节、现行参数、有效期与迁移条件 |
| 制作Word和图时 | `workstreams/template/format_spec.md`、`route_reference.md`、当前图稿及MathType状态 | 原模板视觉规范、A4重排、公式和图片最终验收 |

默认不加载：21篇共2122页全文、101页学姐论文全文、167页网络论文全文、整个前置HTML、转换日志全集、完整聊天历史。出现具体矛盾再定位原页；没有全文的数据源不依靠摘要补造模型细节。

主Agent负责论证、模型取舍、跨节一致性、写作与最终验收。继续委派时只派独立且可核验的子任务，例如单个模型原式核查、单类政策参数复核、实际Word排版验收；仍使用gpt-6-sol/xhigh，最多3个leaf并行。原文证据未足以决定方法时，不让多个agent各写一套完整申报书再拼接。

已完成材料可以直接复用：首轮原框架、模板和转换结果；第二轮三篇定向证据卡；另一Agent已有的政策、资料入口和调查工具。未取得的配套ZIP及代码不列入已验证能力。

下一阶段的具体成果是第四、第五部分正文初稿与逐段创作依据。正式交付前，核验关键模型、MathType新建及回编辑、A4分页与路线图实际版宽。MathType环境不可用时可完成正文内容稿，不能将其标为最终合规DOCX。
