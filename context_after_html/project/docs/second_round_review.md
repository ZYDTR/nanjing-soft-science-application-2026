## 制作和数据方面仍需继续的事项

正式ZSG公式尚须按南京的可调投入和非可调条件逐式核验。外部Liu等（2021）的科技资源ZSG论文只取得出版社摘要与首页预览，未取得完整方法；没有把它当已读全文。新稿保留这一方法方向，但不编造其算法或承诺求解结果。

MathType的本地新建和回编辑能力仍未证明。本轮通过既有Windows连接Skill作一次只读探针，连接被拒绝，未进入Windows环境，未安装或修改软件；[检查记录](../research/mathtype_round2_status.md)说明了所能得出的范围。

导师支持与渠道预期不等于已取得微观台账。写作采用“拟获取”和明确对象、字段、匹配与分层样本；需要实际数据盘点后才能产生南京的实证配置结果。
