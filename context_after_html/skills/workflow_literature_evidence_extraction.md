# 文献证据提取

类型：Workflow。创建：2026-09-23。

## 目标与输入

把一篇论文转化为可核查、可用于研究设计的证据包，让另一位读者能找到承重证据，并分清作者做了什么、哪些地方不能照搬。

调用者提供原文路径或链接、本次要回答的研究问题、输出目录。已有转换件、转换日志和相关项目背景可作为额外输入。未给研究问题时，以对象、数据、方法、主要发现及适用边界为范围；不必为此停下询问。

这是证据提取能力，不承担整个综述的选题、研究方案拍板或申报书写作。默认定向精读；不能把选读标为全文精读。此 Skill 不授予 agent 调度、联系第三方、上传原文或修改源文件的权限。

## 完成时交付什么

在指定目录交付 `evidence.md` 和 `reading_log.json`。关键公式、关键表格或转换存疑页面需要附 `evidence/` 下的原页图。没有关键图表的文本论证不必机械增加截图。检索中发现的否定结果、零结果与不支持原设想的证据同样记录。

`evidence.md` 包含以下信息；结构可按论文本身调整：

- **来源与阅读范围**：题名、作者、年份、来源文件/稳定链接，原文件与转换件的关系；实际阅读章节和物理页，是否有无法访问或识别的页。书目信息以原文核对，缺失项写“未见”。
- **研究设计**：对象和时期、观察单位、样本进入和排除方式、样本量、数据入口、资源与结果变量的含义、计量单位和时间顺序。区分作者报告的数据与自己取得的数据。
- **方法与假设**：模型解决的问题、关键式及符号、识别或优化假设、预算/边界/可行性约束、算法及可用复现材料。对理论文章可写“不适用”并解释，不能编造经验样本。
- **发现与可信范围**：核心发现及页码、稳健性、作者承认的限制、自行发现的疑点。没有复算就写明未复算，不能声称已复现。
- **迁移判断**：对当前问题能借鉴什么，必须改变什么，不能据此推出什么；每项判断回连证据编号。把“作者原意”与“本次研究建议”分别标明。
- **验收记录**：哪些内容已原页核对，哪些仅文字提取，哪些仍无法确认。遇到工具失败保留可定位的错误信息和日志路径，不能用成功退出码替代验收。

承重断言使用稳定编号，例如 E01、E02。最低定位格式为“E01：……；PDF 物理 42 页／印刷 30 页，表 3-2”。物理页从 1 开始。没有印刷页码就写“无”；未读取正文不能给出正文页码。网页使用小节、表号或公式号定位；不要猜造页码。

`reading_log.json` 的结构示例（字段值按实际填写，不照抄示例事实）：

```json
{
  "title": "论文题名",
  "source": "/absolute/path/original.caj",
  "readable_file": "/absolute/path/converted.pdf",
  "research_question": "这篇论文能否支持研究中的资源配置模型？",
  "reading_level": "targeted",
  "total_pages": 100,
  "read_ranges": [
    {"physical_pages": "1-6", "method": "native_text", "purpose": "书目与目录"},
    {"physical_pages": "40-44", "method": "page_image", "purpose": "核对模型与结果表"}
  ],
  "claims": [
    {"id": "E01", "physical_page": 42, "printed_page": "30", "locator": "表3-2", "verification": "page_image", "asset": "evidence/page-42.png"}
  ],
  "unresolved": ["尚未取得作者计算代码，未复算"],
  "full_text_read": false
}
```

`reading_level` 采用 `metadata_only`、`abstract_only`、`targeted` 或 `full_text`；只有确实读完正文、附录等相关内容才使用最后一种。单页索引可用数组代替范围字符串，但要保持可理解。JSON 与证据卡阅读范围必须一致。一条断言跨多页时，可用主定位加 `supporting_pages` / `assets` 数组，或采用 `physical_pages` 数组；注明各处是看图核验还是仅文字读取。声称“未见”时交代检索和阅读范围，不能由局部未见断言全文不存在。

## 证据可信的验收标准

1. 每条决定模型采用、指标取舍或结论写法的断言都有证据编号与原文定位；不由论文题名、摘要或引用别人的段落反推其实际做法。
2. 关键公式中的方向、上下标、约束和变量含义，关键结果表中的样本口径与异常数值，已经对照原页。OCR 和纯文本仅用于导航，不能独立证明数学关系。
3. 读者能从卡片辨认观察单位、样本时期、数据来源及方法适用条件；原文没报告或本次没读到的项目如实区分。
4. 原文发现、作者解释、提取者疑点和迁移建议不混写。相关性、效率测度、配置模拟、机制解释、因果效应按原研究实际证据表述。
5. 如仅取得摘要、页面残缺或工具不可用，交付现有证据、失败位置和待补项即完成一次受限提取；不能伪造“完整完成”。调用方据此决定是否进一步投入。
6. 输出文件可读取，证据编号和图片路径一致。无需为了验收重复转换全部材料或复现与任务无关的所有数值。

## 可用资源与阅读策略

优先利用已有可靠转换件、目录和原生文字定位相关章节。影像页可局部 OCR 或直接看图；原文阅读仍按问题选择，避免把整个材料库塞入上下文。阅读目标涉及某公式时，通常还需读其变量定义、样本及相邻结果，不能只截一个式子。

工具按当前环境能力选择；PDF 的渲染、抽取与新建遵循适用的 PDF Skill。CAJ 先辨认容器和已有转换记录。需要新转换时保留源文件，输出到独立目录；依赖安装优先任务内隔离。已经可用的转换件不必重做。默认不上传未公开原文到外部转换网站。

多阶段实证尤其要核查变量桥接：前一模型的哪个输出，以什么年份、单位和聚合规则进入后一模型，表格描述统计能否对上。方法名称、正文方向、数学式与软件实际设置分别核对；缺少工程文件时不能由其中一项替作者决定真实运行设置。样本量的作者自述、通用方法条件和当前项目可得样本分别记录。

对“网络”“效率”“能力”等核心概念，核对它实际测量的是记录、数量、感知量表还是模拟值。网络研究按需要查节点身份、真实关系、方向/权重、时间及覆盖边界；自报合作程度不自动构成可重建的关系网络。

若已有转换日志警告，优先验证涉及研究判断的页；可以保留未核完的其他警告，但不能将其隐去。对开放网页或新检索论文用当前可用工具核查原始来源，别把搜索摘要当正文。

“回看原页”须说明实际层级：直接原PDF、由CAJ/HN转换的PDF页图、或OCR文字。仅核对转换页图不能证明与原容器逐页完全一致；有警告时分别记录受影响页数与警告行数。对提出优化模型的文章，区分模型式、候选全集、参数/约束值和实际求解结果是否公开；有模型式不等于已有实证优化解。多模块论文的单位、时期和数据来源逐模块列明，不把不同尺度拼成同一实证链。

## 已发生的失误与应对

- **转换成功却有黑页或异常尺寸**：在 CAJ/HN 试跑中出现过。文件能打开、页数一致仅说明容器可读；关键页仍需渲染检查。
- **公式提取打乱不等号和下标**：纯文本曾把模型角色和方向弄混。对影响研究设计的式子回看原页，保留图证和自己的符号解释。
- **把原文异常当提取错误，或直接当可靠结果**：试跑论文 CCR 表中出现大于 1 的效率值及缺失产出。原页确实如此，但未获解释前不能用来校准新模型；记录疑点，不擅自“修正”原作者结果。
- **把机制层与方案层混在一起**：框架迁移曾把机制种类误当三个初始分配方案。先核对概念的层级、公式对应章节和实际计算对象，再判断如何迁移。
- **多个方法看似相连，变量实际上无法对账**：DEA+QCA试用论文的后阶段结果统计不能与前阶段公开表值直接对应，且缺少年份与聚合说明。保留为衔接缺口，不以方法名称齐全推断实证链完整。

## 验证范围

初版来自南京软科学项目的 CAJ 转换、陈才华文献试读及原框架回核经验。2026-09-23在原生文字的DEA/QCA论文、问卷网络论文和HN影像科技计划论文中进行了三次独立leaf试用；主Agent回读报告并核查关键页后补入变量桥接、多页证据、测量类型与转换核验层级。完整验收记录由调用项目 `adhoc_jobs/nanjing_soft_science_2026/docs/second_round_review.md` 保存；未据此宣称覆盖所有格式或所有学科。
